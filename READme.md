# Student Management System

A full-stack, role-based Student Management System built with Django. The system manages students, teachers, courses, enrollments, and academic results through dedicated Admin, Teacher, and Student interfaces. It also includes Django Admin integration and Google Gemini AI features for student performance summaries and enrollment reports.

---

## 1. Project Overview

The Student Management System is a centralized academic management platform for managing students, teachers, courses, enrollments, and academic results.

The application uses Django Authentication, Groups, and Permissions to implement Role-Based Access Control (RBAC), ensuring that Admin, Teacher, and Student users can access only the functionality and data allowed for their role.

The system also integrates Google Gemini AI to generate individual student performance summaries and full enrollment reports.
